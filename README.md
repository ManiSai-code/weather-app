# 🌤️ Node.js Weather Logger

A full-stack web application that allows users to search for real-time weather conditions in any city. The app logs the search history and displays it using a backend API.

**🔗 Live Demo:** [https://weather-app-manisai.onrender.com/](https://weather-app-manisai.onrender.com/)

---

## 🚀 Features
* **Real-Time Weather:** Fetches live temperature, description, and weather icons from the OpenWeatherMap API.
* **Search History:** The backend server stores the last 5 searches in memory and displays them to the user.
* **Error Handling:** gracefully handles invalid city names or API errors.
* **Responsive Design:** Works on both desktop and mobile.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Backend:** Node.js, Express.js
* **API:** OpenWeatherMap
* **Deployment:** Render
